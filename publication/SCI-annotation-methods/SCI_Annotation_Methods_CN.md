# 像素级根系标注与数据集划分

## 1. 数据来源与标注对象

本研究以已完成时期间匹配的微根管RGB图像为输入，建立用于根系与背景语义分割的像素级参考掩膜。数据集由既有244张256×256像素标注图像和补充66张500×500像素标注图像组成，共310个标注父图文件。既有图像来自0353-2-B3观测位置，包含36个基础空间窗口及25个平移窗口在4个时期的图像。补充图像覆盖0353、A017和Q1三个种质的18个观测位置，分别为24、22和20张；按T1—T4划分的实际图像数分别为18、16、15和17张。缺失的6个观测时点仅在元数据中记录，不以空白图像或全背景掩膜补足。

补充区域依据根系可辨识性选取，在每个观测位置沿用相同的已匹配坐标提取500×500像素窗口，并保留全部实际存在的时期。图像文件数用于描述数据组织规模，不等同于独立生物学重复数。310个父图文件及其后续裁块均保留观测位置、时期和源图坐标，以追溯空间与时间依赖。

## 2. 像素级人工标注与标签编码

采用自建浏览器界面进行像素级人工标注，并将最终保存的二值掩膜作为训练参考。界面支持以原始像素为单位的前景绘制、背景擦除和显示缩放；显示操作不改变导出掩膜的尺寸和坐标。参照土壤根系图像语义分割的目标定义[1]，可辨认的根体像素定义为根系前景，土壤、颗粒、水滴高光及裂隙等非根结构定义为背景。根系的颜色、褐变程度或时序状态不构成额外的二值分割类别。

参考掩膜采用无损PNG保存，编码为0表示背景、255表示根系，训练时分别映射为0和1。本版实际使用的标签仅含上述两种有效编码。标注文件中的二值mask层通过游程编码解码恢复为原图大小，按图像标识、尺寸和SHA-256与RGB图像配对。程序检查图像—掩膜尺寸、像素编码和文件哈希，并确认裁剪前后对应像素一致；颜色、时间及存活属性层不参与V35二值模型训练。全部参考标签以原始提交记录的最终二值层为准，来源信息随数据记录保存。

## 3. 250×250像素裁块与完整覆盖

为统一网络输入，在现有匹配网格上将全部父图转换为250×250像素裁块，裁块阶段不进行尺度缩放或插值。每张500×500像素补充图像分为四个不重叠象限，其左上角坐标依次为(0,0)、(250,0)、(0,250)和(250,250)，得到66×4=264个补充裁块。

对每张256×256像素既有图像，为保留边缘像素，分别从(0,0)、(6,0)、(0,6)和(6,6)提取四个250×250像素角部窗口，得到244×4=976个裁块。四个窗口的并集覆盖原256×256像素区域，因而不以中心裁剪丢弃边缘标签。最终得到1240个裁块。程序以逐像素覆盖矩阵核验所有父图像素及根系标注像素均被至少一个裁块覆盖。上述角部窗口高度重叠，因此1240表示训练视图数量，不能解释为1240个独立样本。

## 4. 空间—时间分组与数据集划分

考虑同一根系在相邻空间窗口、平移窗口和连续时期中的重复出现，划分在父图及其空间关联组层面完成，而非将250像素裁块独立随机分配。依据结构化数据划分原则[2,3]，对同一观测位置中矩形范围相交的窗口建立连接，并以连接关系的传递闭包形成空间连通组；同一窗口的全部时期、平移版本以及后续产生的子裁块均继承同一组归属。该规则阻止本轮划分中同一源图像素直接进入训练与监测两侧，但不等同于按整根管或整种质留出的验证。

本轮不沿用此前的训练、验证和测试身份。固定随机种子20261125，将包含任何补充图像的空间组全部划入训练集，同时将与其重叠的既有图像划入训练侧；从剩余仅包含既有图像的完整空间组中分配48张父图用于内部开发监测。最终48个空间连通组中，41组用于训练、7组用于监测。训练集包含196张既有父图和全部66张补充父图，共262张；监测集包含48张既有父图。对应裁块分别为1048和192，占全部裁块的84.52%和15.48%。本研究未设置独立测试集。

## 5. 训练阶段的数据使用与监测计分

所有补充66张父图及其264个裁块均纳入训练。每个训练轮次完整遍历1048个裁块，不再从250×250裁块中随机截取更小区域；100轮共完成104800次裁块访问，其中补充裁块为26400次。补充裁块的训练损失权重设为既有裁块的6倍，以提高其在继续训练中的贡献。

数据增强仅在训练划分确定后实施。几何增强包括随机0°、90°、180°或270°旋转，以及各以0.5概率施加的水平、垂直翻转；RGB与掩膜执行完全相同的几何变换。亮度乘数与gamma指数均在0.9—1.1范围内随机采样，且仅作用于RGB图像。监测图像不施加随机增强。计分时，以250像素窗口、188像素步长进行重叠预测并采用Hann权重拼接概率，在父图网格上以0.5阈值计算指标，每个有效源像素只计一次，避免将重叠裁块重复纳入监测统计。

## 6. 内部监测指标的解释范围

本轮继续训练继承了前序模型权重。按父图文件标识追溯，当前48张监测父图中有44张曾在前序权重训练中使用。因此，该集合仅用于继续训练的内部开发监测和权重选择，相关指标不应解释为严格未见样本测试或跨根管、跨种质泛化性能[4]。空间组在本轮划分中不相交，不能消除既有权重的历史数据暴露。

本节定义的二值标签用于V35根系/背景模型。后续TRGD（V90）读取同一RGB和固定的V35根系前景，仅在根系像素内赋予新生根或既有根标签；延伸和持续状态并入既有根。该时序输出与本节的根系/背景监督类别分别定义，不将当前预测图计作新增人工参考标签。
