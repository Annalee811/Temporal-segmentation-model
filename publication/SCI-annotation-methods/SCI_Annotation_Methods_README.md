# SCI方法文本：像素级标注与最终数据集划分

正文按最终实际方案撰写：310父图、1240相关裁块、1048训练/192内部开发监测，补充66张全部训练。中文和英文正文一致，Word可编辑，英文PDF使用Times New Roman。

原有244个文件含平移视图，不能称244个独立生物样本；1240为裁块数。当前监测父图48张中44张有前序训练暴露，因此仅作为内部开发监测，不能称严格独立验证。没有编造标注者人数、标注时长或观察者间一致性指标。

文件：bilingual.docx为中英双语可编辑版；CN.md和EN.md为可复制正文；EN.pdf为英文排版；references.bib为参考文献；evidence.json为本次核对事实。原始标注与数据划分记录的来源由evidence.json指向，历史记录不改写。
