# 同一根系图的推理结果为何不同

已对齐到0353-1-B3、T1的同一500×500像素区域，共有视野坐标x=1870、y=12。两种方式的RGB逐像素相同，均使用同一第91轮V35权重、250px窗口、188px步长和0.5阈值。

黄色500px图来自先裁500px再预测；蓝色图来自先预测2382×1028共有视野再裁出同一区域。滑窗原点与边界补齐位置、窗口内容不同；网络的GroupNorm按窗口空间统计，卷积边界上下文也不同，因此同一物理像素的概率会变化。独立500px推理已用相同权重重新运行，完全复现已发布的500px掩膜。

整共有视野预测再裁剪：2862个根系像素。单独500px预测：3764个根系像素。两掩膜共1068个像素不同，其中985个仅出现在单独裁块推理中，83个仅出现在整视野推理中。颜色和展示缩放并不能解释全部差别。

V90与其输入的整共有视野V35前景逐像素一致，对齐裁剪后也是0个差异像素。此前的前景一致性核验对象是这两者，不是独立500px输入与整视野输入之间的比较。

统一展示口径：完整共有视野预测一次，再从同一概率、掩膜、时序标记和RGB中裁出任何展示区域，不对展示裁块重新推理。新的导出工具export_common_roi.py已实现此规则。V35_context_canonical_V35.png与V35_context_canonical_V90.png为同一500px区域，只有标记颜色/语义不同，根系支持域完全一致。T1的蓝色是既有根基线。

未更改已发布模型、18个视野预测或提交标记，未通过粘贴标记改变模型结果。所有统计来自实际掩膜。
