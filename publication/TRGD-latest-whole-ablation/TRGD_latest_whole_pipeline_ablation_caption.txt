Whole-pipeline inference ablation of deployed Temporal Root Graph Decoding (TRGD, V90) with the latest V35 root support. TRGD off uses frozen V66 temporal priors and bypasses the entire V90 process. TRGD on applies the coupled ConvLSTM+GAT, Axis root-axis constraint and Junction connection constraint as one process. All components are switched as a bundle; no component-specific ablation or new training is performed. (A/E) Matched control design. (B/F) Dice of new roots, existing roots and their unweighted mean (Macro Dice). (C/G) New-root precision, recall, Dice and IoU. Δ is a percentage-point difference; a negative recall change is shown explicitly.

Both conditions use identical matched RGB pixels and the V35 epoch 91 foreground, without registration, image rescaling or foreground changes. Foreground identity is checked across all 66 available images at 18 observation positions. Temporal accuracy is scored only on the available previously annotated sequence0353-2-B3 atT2–T4, using 468203 reference-root pixels. T1 is context only. The same 17438 reference-root pixels missed by V35 are retained as missed predictions in both controls. Existing and legacy extension labels are merged; only new-root and existing-root classes are scored. Background pixels are outside this temporal metric domain, so these precision/recall values describe classification on the reference-root support, not full root/background segmentation. A separate conditional analysis on 450765 detected reference-root pixels is supplied and is not substituted for the main metric.

This is a development-sequence inference ablation of the frozen deployed transfer adapter. Its reconstructed graph preparation differs from the archived original preprocessing, as listed in evaluation.json. The original V90 weights are preserved, and there is no independent temporal test set or repeated training experiment. These temporal metrics must not be confused with V35 binary root/background Dice 89.85% computed on 48 monitoring parent images. The combined A–G figure retains these distinct evaluation domains. No confidence interval, significance claim or inferred AUC is added from hard class maps.
