submitted_labels：你上传JSON的根系标记直接叠加到对应原始RGB图像。
model_predictions：固定完成100轮的新版V35，按内部验证Dice选择第32轮权重，在完整原始视野预测后，按相同坐标提取500px窗口并叠加。
